Прогнано 2026-11-16 на Windows 11, Python 3.12, Git Bash. Шаги взяты из [`SKILL.md`](../skills/chistovik/SKILL.md), тексты из кейсов в [`evals/`](../evals/). Тексты сохранялись во временную папку системы, в проект ничего не писалось.

## 1. Главный сценарий: сообщение рекрутеру

Кейс [`evals/hr-message`](../evals/hr-message/prompt.md). Запрос: «Почисти, чтобы не было похоже на нейросеть. Это я рекрутеру в телегу отправлю».

**Шаг 1–2.** Текст прочитан целиком. Сообщение для Telegram, значит жанр `chat`. Сохранён в `orig.txt`.

```
$ python chistovik.py scan orig.txt --genre chat

Подсказки к находкам в протоколе сокращены.

**Шаг 3.** Находки сверены с [`contract.md`](../skills/chistovik/references/contract.md). Все 11 жёстких подтверждены: ни одна не цитата, не термин и не норма жанра. Из спорных подтверждены все шесть: для чата сообщение длинное, восклицания и ёлочки выдают сгенерированный текст, «В рамках проекта» убирается без потерь. Сверх сканера замечено одно: «настоящий сдвиг для всей команды» ничем не подкреплён, это раздутый вывод. Его убираем, а не заменяем.

**Шаг 5.** Правка только по найденным местам. Факты из исходника: Анна, Python, 4 года, Django, PostgreSQL, «Ромашка», сервис платежей, удалённая работа. Новых фактов нет. Размытое «обсудить возможности сотрудничества» стало конкретным вопросом о вакансиях: это то же намерение, без новых сведений.

**Шаг 6.**

```
$ python chistovik.py check orig.txt rev.txt --genre chat

Слов было 67, стало 29, изменено около 62%. Жёстких находок было 11, стало 0; спорных было 6, стало 0.

**Шаг 7.** Ответ пользователю по [`templates/result.md`](../skills/chistovik/templates/result.md):

> ```
> Здравствуйте, Анна. Я Python-разработчик, опыт 4 года, работаю с Django и PostgreSQL. В компании "Ромашка" сделал сервис платежей. Ищу удалённую работу. Подскажите, есть ли у вас сейчас подходящие вакансии?
> ```
>
> Что поправил, 9:
> - «Надеюсь, у вас всё хорошо!» → убрал: пустая вежливость, сразу видно шаблон
> - «Давайте разберёмся: я — Python-разработчик с опытом 4 года» → «Я Python-разработчик, опыт 4 года»: разгон и тире
> - «Обладаю навыками работы с» → «работаю с»: канцелярский штамп
> - «В рамках проекта в компании «Ромашка» я реализовал» → «В компании "Ромашка" сделал»: канцелярит, ёлочки
> - «— и это не просто сервис, а настоящий сдвиг для всей команды» → убрал: эффект без фактов
> - «коммуникабельный, ответственный и целеустремлённый специалист» → убрал: качества без примеров
> - «**Ищу:** удалённую работу» → «Ищу удалённую работу»: в мессенджере жирного не бывает
> - «Уверен, что мой опыт будет полезен вашей команде» → убрал: опыт уже показан фактом
> - «Буду рад обсудить возможности сотрудничества!» → «Подскажите, есть ли у вас сейчас подходящие вакансии?»: конкретный вопрос вместо штампа
>
> Проверка: пройдена. Жанр: сообщение в мессенджере. Изменено около 62% слов, для чата это нормально: было 9 предложений, стало 5.

Сверка с критериями кейса ([`graders/result.md`](../evals/hr-message/graders/result.md)): все факты на месте, штампов, тире, жирного и списков нет, 5 предложений, в конце один вопрос, после текста список правок и результат проверки. **Пройден.**

### Контрольная проверка: неудачная правка

Чтобы убедиться, что `check` ловит ошибки правщика, та же сверка запущена на нарочно испорченной версии: опыт «5 лет», «2 млн транзакций», выпал PostgreSQL, добавлено «Без воды. Только суть.».

```
$ python chistovik.py check orig.txt bad.txt --genre chat
Чистовик 0.1.0: Проверка не пройдена.
Слов было 67, стало 29, изменено около 75%. Жёстких находок было 11, стало 1; спорных было 6, стало 2.

Ошибки:
  - Пропало число: «4 года».
  - Появилось число, которого не было: «5 лет».
  - Появилось число, которого не было: «2 млн».
  - Пропало название: «PostgreSQL».
  - Новая находка: Штампы самого правщика [bez_vody] «Без воды.». Это штамп самих «очеловечивателей». Убери.

Предупреждения:
  - Пропала цитата или название в кавычках: «Ромашка».
  - Новая находка: Ритм и форма [dlinny_chat] …
  - Новая находка: Ритм и форма [rublenye_frazy] «Без воды. Только суть. Ищу удалённую работу. Когда удобно созвониться?».
  - Изменено около 75% слов. Для правки это много: правь только найденные места.
$ echo $?
1
```

## 4. Голос

Кейс [`evals/voice`](../evals/voice/prompt.md). Для прогона `CHISTOVIK_HOME` указывал во временную папку, чтобы не создавать файлы в домашней папке.

```
$ python chistovik.py golos build chat v1.txt v2.txt v3.txt
Голос «chat»: образцов 3, слов 50.
Образцов мало: профиль черновой. Лучше 3 текста и от 600 слов одного жанра.

$ python chistovik.py golos show chat
- Предложения в среднем 8.3 слов, разброс 5.4. В абзаце около 2 предложений.
- Длинное тире почти не ставит.
- Букву ё не пишет, везде е.
- Восклицательных знаков почти нет.
- Эмодзи не использует.
- Ставит смайлики из скобок: 40 на 1000 слов.
- Часто начинает предложения с маленькой буквы (100%).
- К собеседнику на «ты».
…
```

Сравнение с двумя текстами:

```
$ python chistovik.py golos compare chat alien.txt   # «Добрый день! В рамках задачи — и это важно — я осуществил миграцию…»
похожесть на голос «chat»: 57 из 100.
  - длинные тире: у автора 0 на 1000 слов, в тексте 105.3 на 1000 слов
  - восклицательные знаки: у автора 0 на 1000 слов, в тексте 105.3 на 1000 слов

$ python chistovik.py golos compare chat own.txt     # «глянул логи. база легла из-за пула, поправил конфиг, вроде норм)…»
похожесть на голос «chat»: 80 из 100.
```

Карточка называет маленькие буквы в начале, отсутствие ё и тире и смайлики из скобок. Профиль помечен черновым. **Пройден.**
